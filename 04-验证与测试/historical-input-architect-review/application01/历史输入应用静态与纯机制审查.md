# 历史输入应用静态与纯机制审查

结论：本轮未发现新增静态阻塞，19项纯检查通过；应用尚未获得独立PG／HTTP／对象机制通过。候选SHA256 `3d917c3190eca381e43d647bbf7a29422faebb1653605a45784a0a76e10fba45`，SQL C为 `a5d3823cfa1f9cd360649114da8026a07bf5b93b13ec900c22226117137c1052`。核对10份源码及37份参考输入原字节，没有读移动中的main作为证据。

静态调用链支持以下边界：真实历史submission固定正文与原submitted_at，不构造旧review或倒填系统known／created时间；精确主体和每份body／tender／supplement需要当前confirmed证明及其完整原件权威，公开时间不能代替本方知晓。快照body引用不进入招标必要集合，正文仍独立固定；不支持资料、来源、图页／证据或全文容量缺口拒绝。每项评分条件使用整份完整正文及全部物理页1..N，不用RAG top-k或摘要。

capture持RC／group／bid／图权威锁，只读后退出；build／对象stage位于事务外；publish重新capture并比较完整摘要，再只提交元数据、typed映射与SQL封口。GET及幂等重放先取得不可变元数据，事务外核实际对象SHA／尺寸，再通过新事务重读当前资格；旧历史可以显示stale，重放不能返回旧green。原HIST02锁入口RC前置复用，metadata只在此前读取不可变header，不以旧快照执行新的当前资格判断。封口后的子行追加由SQL拒绝；来源／证明／最新parse／主体决定变化应使旧输入失效。

请求模型拒客户端origin、旧created_at、review_id、historical_as_of和正式资格等额外字段；真实origin含synthetic持续synthetic，其余uncertain，execution_available与正式资格均不可用。该组件是当前创建的历史重建输入，没有由此开放StageA真实训练、研究留出、评分producer或模型认证。

19项纯检查包括整份正文与所有规则不截断、容量在PUT前拒绝、公开／未来／未证明的知晓与生效事实拒绝、客户端伪造历史／正式资格字段拒绝、实际4接口闭合schema、缺首／中页和页数不符拒绝。执行脚本probe_pure.py与原始XML保全；默认数据库、HTTP、对象端口均禁止，0数据库／对象／模型请求、0消费者、0DDL。
