# 人工范围填写与精确证据目录验证

本片在明确本方包修订及要求清单内填写人工观察或完整范围声明，提供冻结包证据目录，并追加独立、不可变的人工范围记录。检查计划与原页弹层的既有验收见[人工检查计划与样式隔离验证](人工检查计划与样式隔离验证.md)，要求清单与历史读取见[要求清单工作面验证](要求清单工作面验证.md)。本报告不借用前述切片的测试计数或截图证明本片通过。

## 实现范围与九种状态

每条要求须明确纳入本次记录，不自动沿用上一次状态或证据。每次 attempt 独立计算，未纳入条款保持 unknown；不能将多次各自检查一部分的记录自动拼接为完整核验。

| 状态 | 界面含义与允许条件 |
| --- | --- |
| `not_provided` | 未提供的人工观察；必须有理由，证据与受检范围可空 |
| `missing` | 缺项的人工观察；必须有理由，不能由检索无结果自动推断 |
| `pending_parse` | 待解析的人工观察；必须有理由，不冒充已取得解析身份 |
| `parse_gap` | 解析有缺口的人工观察；必须有理由，不把缺口当已完整检查 |
| `unsupported` | 不支持的人工观察；必须有理由，不自动认定资料未提供 |
| `conflict` | 存在冲突的人工观察；必须有理由，不替代原规则决定 |
| `unknown` | 明确记录未知；必须有理由，省略的条款也保持未知 |
| `verified` | 人工声明已检查全部目标范围；须明确确认、非空理由及本方精确证据，所有目标页段完整覆盖，目标解析明确冻结，原要求适用；已知数量还须已声明数量检查 |
| `not_applicable` | 人工声明有据不适用；须明确确认、非空理由与证据，原冻结要求已具有不适用结论及适用依据，不能在填写覆盖时改写适用性 |

七种观察状态使用 `human_observation`，证据和受检范围可空；如填写，仍受精确包及目标范围约束。两种正向声明使用 `human_scope_declaration`，另要求来源已精确绑定、当前原决定为 confirmed、原规则来源有效，以及完整、已发布且在有效时间内的来源快照。未映射条款可记录负向观察，但不能绕过适用性与范围门槛作正向声明。

`verified` 只表达人工检查范围，不证明材料项合规、评分通过或正式评审通过。现有规则集没有冻结完整抽取解析身份，`requirement_inventory_complete=false`、`complete=false`、`review_ready=false` 保持；即使每条都声明完整范围，也不能取得正式整包资格。

本方成员的页数未知、逻辑范围未分配、解析身份未冻结等缺口由冻结成员只读派生展示，不自动改写某条要求的状态。当前填写界面对每个分册提供一个连续受检页段；恢复记录如含同分册多个独立页段，保留原记录并锁定，不静默压缩为最后一段。

## 精确包证据目录

目录绑定明确包修订与规范摘要，按冻结解析查询，替代按文件取得最新解析的发现方式。同一文件存在较新解析时，不自动改用较新结果。目录本身只用于发现候选，不直接授权证据选用。

每页响应核对包修订、包摘要，以及逐项文件版本、冻结解析、物理页和完整分册归属集合。共享页保留全部合法 part 归属，不以单一分册覆盖其他归属。分页游标受项目／包／修订范围约束；迟到页通过代次隔离，不能混入其他目录。

读取原句再次请求精确 `/evidence/{id}`，核对 ID、文件版本、解析、物理页、目录声明及已发布状态。身份不符、未发布、撤回或读取失败的引用不可选用。完整范围声明的证据必须属于本方冻结包，并落在本次填写的受检范围内；原规则的权威依据不能代替本方证明。不适用及观察记录可引用本方或权威依据冻结范围内的证据。

本片不编辑原条款、原决定、原证据或历史清单；旧规范正文及摘要仍按原冻结记录读取，不按当前来源重新构造历史。

## 固定上下文、恢复与 ACK 绑定

开启填写时捕获明确清单、权威依据包和本方包修订。当前 head 变化只会阻止新保存，不把原内容自动套入新清单。覆盖追加接口没有 ETag 前置头；请求正文的 `inventory_digest`、`package_digest` 及路径中的当前清单身份共同约束写入，服务端另核当前包 head、规则集、主体／项目／标段／轮次范围、原决定和来源效力。

发送前按成员／项目／包／修订隔离，将冻结上下文、完整正文和幂等键写入 sessionStorage；存储失败零发送。结果未知时锁定编辑与放弃入口，刷新后继续原清单路径、原正文和原键，即使当前选择已换为其他清单，也不改变未决操作。通用前置 409／422／428 不清除已有未知记录；项目关闭仍可原键取回已有 ACK，新建禁用。损坏或范围不符的恢复记录锁定创建。

恢复正向记录可以保留原已明确的人工确认，但所选引用仍须重新读取后才允许作为有效编辑内容。禁用状态不开放修改，读取恢复引用也不能改变父工作面的原请求重试内容。

成功 ACK 除清单、项目、顶层包与摘要外，还绑定当前成员 `actor_id`、逐条要求及要求摘要、逐条包摘要、状态、理由、受检页段、证据 ID 与 `evidence_refs` 对应关系，并要求旧清单完整性标记仍为假。错误成员或嵌套包／引用字段不一致时保留原未决记录，不因顶层身份正确而清理本地操作。

## 样式隔离

父工作面的通用后代选择器排除 `.package-coverage-workspace` 本身及其子树，避免父 article、label、按钮等样式进入编辑器。工作面自身规则使用直接子关系；编辑器 CSS 限定 `.coverage-editor`，排除 `.dialog-backdrop` 及其后代，桌面与移动分支保持相同边界，使用既有语义令牌。

当前证据目录及原句在编辑器内联展示，不新增浮层或 portal，不将证据弹层放入禁用 fieldset。独立只读审查与下述新构建浏览器实测均未发现本片新增样式侵入原页弹层。

## 限制

本片验证使用合成元数据，不等于真实 PDF 已存入对象存储；没有 OSS 原件下载证据时，不能声称原件取回、PDF 视觉核对、OCR 或表格抽取质量通过。冻结解析目录返回正确身份，也不证明其解析正文在业务上准确完整。

正式整包评审／评分／提交链和真实评分精度尚未验收。真实最终提交稿与官方技术分配对样本缺失，不能以人工范围声明或合成观察替代。NA 正向门槛、非空成员缺口及失 ACK 恢复由组件／API反例验证，本次没有浏览器 NA 保存、非空缺口矩阵或断网注入；全部字号／缩放及其他业务模块亦不列为通过。同一分册目前编辑一个连续区间；恢复多段旧请求时保留原正文可重试，编辑锁定，不合并或丢弃区间。
