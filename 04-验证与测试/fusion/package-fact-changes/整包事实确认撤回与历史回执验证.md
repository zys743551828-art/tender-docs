# 整包事实确认撤回与历史回执验证

应用 `5249724`，融合分支，5188／fusion_v7。内部用例按明确冻结档案和当前事实集CAS，接受显式人工confirmed请求，追加新事实、原页依据及人工确认，或替换／撤回当前事实；幂等ACK在同一事务提交后返回。保留根输入、操作者、命令、新旧事实集、事实／决定及依据选择／实际依据摘要。原件字节、事实当前资格、评审／执行／发布标志恒false；新确认后须重新准备和选择，旧prepared及范围声明不改写。

共享事实集写入提供明确依据／沿用政策端口，默认旧策略保持；整包新值只用准确冻结依据。未变事实的原确认仅在唯一原审计与语义身份可证时沿用，不以当前材料头或来源时效抹掉历史决定，也不授当前使用资格。未确认值不自动确认。未变值在数据库内INSERT SELECT复制，保留PostgreSQL JSON数值精度，避免驱动浮点往返。

协调器持RC事务和项目／来源图锁，当前来源在追加后按实际时点再核，防止无revision变化的自然到期；失败回滚事实集、事实、确认、头、审计、命令和事件。来源撤回后仍可撤回当前事实；既有幂等ACK和历史读取不依赖当前来源及可写阶段。历史以不可变package.fact_confirmed／withdrawn审计和准确201 ACK交叉校验，不按最新选择审计；重新封装、空ACK或伪造头部均明确500，不进入新写入。只读历史核准确原冻结根，不查询模型或对象存储。

机器契约为`package-fact-change.schema.json`，保持现有FactInput的字符串／布尔／空值类型边界，人工意图、CAS、理由、依据和回执状态严格验证。不把旧数据库可读的任意JSON值扩成新输入协议，也不以内部模块导入冒称HTTP和表单已完成。
