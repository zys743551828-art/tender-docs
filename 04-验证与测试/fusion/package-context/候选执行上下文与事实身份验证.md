# 候选执行上下文与事实身份验证

2026-10-19；应用 `f011612`，分支 `fusion/bid-workbench`，接续[原件核验](../package-originals/锁外原件核验与二次快照验证.md)。本片构建内存中的候选执行上下文并接入核验前后比较，**尚未完成持久化正式冻结、任务调度或整包执行**。

## 实现与职责

原先原件核验比较包、数据库证据及来源／项目状态，但没有捕获事实和方法配置；期间新增事实、改变人工决定或模型配置也可能继续返回原件观察。本片将这些内容纳入两个只读快照，语义上下文变化返回409 `PACKAGE_REVIEW_INPUT_CHANGED`。

- `package_review_context` 只读取当前事实集权威、全部条目、人工决定、审计依据及证据与所选冻结解析的关联，不走旧事实校验的当前正文／最新解析逻辑，也不取该路径来源写锁。
- `package_review_method` 声明整包方法 `package-review/1`、明确用途 `prebid_compliance`、相关验证／身份／提供商代码摘要和配置。执行器未实现、正式评分资格false，不冒用旧单正文方法。
- `package_review_identity` 纯构造 `package-review-context/1` 候选：明确原输入摘要、主体、方法／政策、事实与决定、来源和时点；防御性复制调用方数据。语义摘要不含自然推进的观察时点，完整快照摘要包含时点；拒绝无时区、用途不一致和伪造资格。
- 原件协调服务只调用捕获并比较语义身份；前端 `packageReviewContext` 边界函数验证响应，组件只折叠展示计数和用途，不把候选作为执行回执。

事实值及审计依据以PostgreSQL JSONB文本捕获，保留数值表示，避免二进制浮点进入规范摘要。未确认、拒绝及缺依据的条目均保留，不能静默丢掉。包外或缺证据的事实关联为unproven；即使关联到明确冻结解析，也仅说明范围关联，不表示事实依据资格复审通过。响应有事实时 `facts_binding=unproven`，无记录时empty；两者均不授正式资格。

原件响应新增摘要、用途、时点、事实集ID和计数，不返回事实值、审计依据、原件定位或证据正文。旧包manifest、`review-content/1`算法和单正文方法保持原样。候选没有持久化，不新增命令或任务；无DDL、初始化或角色权限变化。
