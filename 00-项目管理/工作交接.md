## 3. 本机开发环境（Windows）

工具都装在 D 盘（用户要求：非必要不装 C 盘）。

| 工具 | 位置 | 说明 |
| --- | --- | --- |
| Python 3.11.9 | `D:\tools\Python311` | 与后端 Docker 镜像一致 |
| Node.js 22 | `D:\tools\nodejs22\node-v22.23.2-win-x64` | 必须用 22：Node 24 下前端测试的 MSW 请求拦截挂起，151 项失败 |
| pip / npm 缓存、npm 全局目录 | `D:\tools\cache\pip`、`D:\tools\cache\npm`、`D:\tools\npm-global` | 用户环境变量 `PIP_CACHE_DIR` 与 `~/.npmrc` |
| Docker Desktop | `D:\Docker\Docker` | 其 WSL 数据盘在 `C:\Users\74355\AppData\Local\Docker\wsl`（约 1.7 GB），迁到 D 盘需在 Docker Desktop 设置里由用户操作 |

已建好的依赖环境：`tender-app/backend/.venv`（`pip install -e '.[dev]' bandit`）、`tender-research/.venv`（`pip install -e '.[dev,store]'`）、`tender-app/frontend/node_modules`（`npm ci`）。

后端测试需要可建库的 PostgreSQL。本机用一次性容器：

```bash
docker run -d --name bidwb-test-pg -p 127.0.0.1:5432:5432 -e POSTGRES_HOST_AUTH_METHOD=trust postgres:16.15-bookworm
```

在 Windows 上运行 Python 程序前设置 `PYTHONUTF8=1`，否则中文配置文件按 GBK 读取会失败（该设置对 pytest 内部启动的 alembic 子进程仍不够，见验证报告 2.8 节）。
