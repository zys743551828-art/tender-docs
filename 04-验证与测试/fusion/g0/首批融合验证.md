## 验证命令与证据

```text
python -m pytest -q tests/test_bid_packages.py tests/test_review_identity.py
python -m pytest -q tests/test_bootstrap_role_isolation.py tests/test_bootstrap_role_isolation_pg.py
python -m ruff check apps/api apps/worker packages/domain deploy
python -m ruff format --check apps/api apps/worker packages/domain deploy
python -m mypy deploy/bootstrap_fresh.py packages/domain/bid_packages.py
python -m bandit -q -ll -r apps/api,apps/worker,packages/domain,deploy
python -m apps.api.export_openapi
python deploy/check_compose.py --env-file .local/check-compose.env
```
