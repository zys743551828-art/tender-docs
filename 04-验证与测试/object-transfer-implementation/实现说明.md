# 同源私有对象传输

## 当前实现

`apps/api/object_transfer.py` 提供同源 FastAPI router。原生 OSS 环境的创建上传、刷新授权、下载元信息由后端开发集中接入；本模块不修改云桶 CORS、ACL 或版本设置。现有 S3 开发环境继续使用既有路径。

| 接口 | 授权与行为 |
| --- | --- |
| `PUT /api/v1/object-transfers/uploads/{upload_id}?ticket=...` | 实际 Cookie 会话、正确 Origin、`X-CSRF-Token` 与应用短期票据；PDF 字节暂存，返回对象 ETag；不代替 complete 或 Worker SHA 核验 |
| `GET /api/v1/object-transfers/versions/{version_id}?ticket=...` | 实际 Cookie 会话与应用短期票据；流式返回原件字节，中文文件名按 RFC 5987 编码；Range 请求明确返回 200 全量及 `Accept-Ranges: none` |

票据最长 15 分钟，并收窄到会话及上传本身的过期时间。票据绑定会话 ID、成员 ID、业务对象 ID、实际对象 key、尺寸；上传再绑定项目、当前 revision 与 PDF 媒体类型，下载再绑定原始文件名。URL 中不含对象 key、正文、云签名或云凭据。API 必须关闭访问日志，反向代理同样不得记录完整 ticket query。

两种 Grant 的 URL 均以受信部署配置 `APP_ORIGIN` 构造绝对同源地址，满足现有 `format: uri` 契约。该值必须是浏览器规范序列化的 HTTP(S) origin：不含路径（包括末尾斜杠）、查询、片段、用户信息或非规范默认端口；可使用本地开发 IP、localhost、IPv6 与非默认端口。模块拒绝不合法配置，不使用请求 Host 或 `X-Forwarded-*` 决定下载或上传目标。

上传接收准确的 `Content-Length` 与 `application/pdf`，同时按实际读取量限制大小、检查最终长度与 PDF 文件头，拒绝压缩编码。默认最大 100 MiB，配置 `OBJECT_TRANSFER_MAX_BYTES`，同时受 `MAX_UPLOAD_BYTES` 限制；传输端最大可配置到 256 MiB。默认总 deadline 为 300 秒，配置 `OBJECT_TRANSFER_DEADLINE_SECONDS`，范围 1 至 900 秒。临时原件使用自动删除的 600 权限临时文件。原生 OSS 端口目前需要明确 bytes，因此发送前仍会有一份限额内的内存字节副本。

## 竞态与恢复

网络传输期间不持有数据库行锁。每个 PUT 使用独立的 `staging/{bid}/{upload}/transfers/{UUID}`，先完成对象写入，再以与现有命令相同的 `bid → upload/transfers` 锁顺序短事务复核当前授权状态、批次状态、过期时间、revision、暂存 key 与中止状态，通过后切换 `uploads.staging_key`。不修改文件绑定、版本预期或正式 blob。

若 complete、abort、refresh 或会话撤销先发生，本次请求不能公布新 key。成功 PUT 后旧票据也因实际 key 改变而失效；若成功响应丢失，前端应读取 parts / 当前上传状态，必要时刷新授权，不把旧票据冲突视为 Worker 已核验。

本系统临时 key 在被 Git 忽略的 `.local/object-transfer-temporary-keys.jsonl` 登记，目录 700、文件 600。登记只含系统生成 key、环境命名空间与非秘密对象定位元信息；不记录正文、文件名、Cookie、票据或凭据。该文件是待核对候选登记，包含仍可能被使用的 key；未来 GC 必须先检查数据库 uploads / blobs 引用和环境命名空间，不能直接逐项删除，更不能扫描或清理用户原桶中其他对象。

下载实际对象尺寸与数据库记录不符时，在发送响应头前返回冲突。读流过短、超时或客户端中止时关闭原生对象连接；响应头已发出的失败通过中止流体现，不能伪造完整下载成功。
