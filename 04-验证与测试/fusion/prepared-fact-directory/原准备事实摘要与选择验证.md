# 原准备事实摘要与选择验证

应用 `6f37a8b`，分支 `fusion/bid-workbench`，预览5188／fusion_v6。范围工作面可读取原准备输入中的事实摘要，按名称和值选择，再核对适用范围；编号保留为准确历史入口。事实目录不使用当前事实头，旧准备输入的值与身份不会随后续事实或来源变化而替换。

## 责任与接口

`GET .../execution-inputs/{execution_input_id}/facts?limit=20&cursor=...`，操作 `listPackagePreparedFacts`，会话必需、只读200，无Command／Outbox／原件调用。limit为1至100，Web每页20。服务端先消费明确scope／冻结根／prepared的已校验不可变packet，随后只从其私有事实快照生成目录，当前来源停用不阻断历史读取。

`bid_package_prepared_facts`负责快照目录与纯摘要投影。按事实UUID稳定排序，签名游标绑定四项scope、冻结根、prepared编号和摘要，并核原facts_digest及末项确实属于原集合；改准备输入不能复用游标。响应携带prepared摘要、原事实集／数量／摘要、逐项fact_item_digest和有界显示摘要。不暴露决定审计依据、原文或对象定位。

名称、原主体、原范围、值摘要和单位各最多240 Unicode码点；任一字段截断均明确preview_truncated。字符串去掉JSON编码后展示，布尔为是／否、null为未填写；数值或结构保留PostgreSQL原JSON文本，避免浮点改写大数。显示投影不修改原快照，不用其重建身份，逐项摘要仍计算完整原item。损坏原值返回存储输入错误500，不混成当前范围拒绝。

`PackagePreparedFactPicker`负责显式读取、分页和按名称选择，`preparedFactDirectory`负责严格身份／摘要／计数／排序／分页核对；重复、倒序、游标循环或跨prepared迟到不采纳。选择后范围组件显示原主体／原范围仅作历史文本，适用对象仍须明确选择结构化ID。当前声明或保存回执的fact_item_digest与所选原摘要不符时拒绝；未知请求保留。选择不自动保存，不授事实或执行资格。CSS仅作用冻结工作面，按钮允许换行。
