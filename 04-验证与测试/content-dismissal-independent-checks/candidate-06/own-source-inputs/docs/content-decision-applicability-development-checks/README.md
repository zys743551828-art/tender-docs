## 行为

- 新检测发现只有正文原件SHA、有效规则语义及原件依据、双侧服务端校验过的断言与证据身份、冻结来源闭包和方法均等价，才可沿用该发现对应的人工dismiss。左右侧互换不改变身份。数值、稿件、证据、方法或来源变化后，新发现保持open，保留旧决定及历史。
- 新发布audit保存决定沿用的依据摘要和实际from_decision_id。物理carried_from链保留，读模型不能凭物理祖先自动授予不适用的人工决定。已存在的不等价沿用行读取为open；用户对该新发现做决定时写该实际发现，不回写旧根的决定。沿用链的迟到祖先dismiss也须证明对实际发现适用。
- 工程断言的主体、范围、属性、值必须具有同一局部逐字关系，不能从同quote内另一个工程或标段借值。简单连接词、重叠主体/范围可证明时接受，复杂无法证明的关系返回诊断/partial；不以此授予复杂语义质量。
