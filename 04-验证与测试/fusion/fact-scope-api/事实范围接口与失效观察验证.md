# 事实范围接口与失效观察验证

应用 `a2c1a2c`，分支 `fusion/bid-workbench`，预览5188／fusion_v6。范围声明已有正式保存／撤回、精确历史和当前状态观察接口，复用[内部追加协议](../fact-scope/事实范围追加协议与持久化验证.md)。主体选择与未知结果恢复界面属后续接入；人工声明和当前匹配观察均不授事实资格、任务启动或发布许可。

## 接口边界

共同路径为 `/api/v1/bids/{bid_id}/packages/{package_id}/revisions/{revision_id}/requirement-inventories/{inventory_id}/frozen-review-inputs/{input_id}/execution-inputs/{execution_input_id}`。

| 方法／后缀 | 操作 | 责任 |
| --- | --- | --- |
| POST `/fact-scope-declarations` | `changePackageFactScope` | 严格Change契约，Origin／CSRF／Idempotency-Key必需；bind或withdraw，201提交ACK；同键恢复原请求 |
| GET `/fact-scope-declarations/{declaration_id}` | `getPackageFactScope` | 明确scope／prepared／记录ID读原manifest与摘要，不被当前来源或链头替换 |
| GET `/facts/{fact_id}/scope-declaration` | `getPackageFactScopeObservation` | 只读观察指定prepared中的原事实、声明链头、冻结身份四种可选主体、当前输入／依据是否匹配 |

HTTP适配、只读观察、写入用例、纯协议和仓储分工独立。提交完成后才返回201；延迟约束失败返回409 `PACKAGE_FACT_SCOPE_REJECTED`，记录和Command均回滚。请求额外授权字段422、无CSRF403、无幂等键428；错scope／记录／原事实404，旧CAS或当前证据不符409。实际OpenAPI与生成TS同步，接口不创建任务或Outbox，不调用原件对象／模型。

观察只允许事实确实位于指定prepared；包内当前新事实不能替换原事实身份。主体选择来自原冻结identity/2，名字只显示，ID负责绑定。当前观察分别返回head、matches_prepared_input、provenance_status和binding_status；明确withdrawn与仍匹配／待重核，全部资格标志false。当前来源停用时旧声明／旧ACK仍可读，当前匹配不再成立，并允许追加撤回。未来声明或检查不会改变旧prepared、旧冻结manifest、证据或报告。
