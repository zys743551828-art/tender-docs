# 要求事实依赖与缺口内部评估验证

应用 `3e579bd`，5188／fusion_v7。`package_input_dependencies`对已消费的准确冻结／prepared与明确事实消费选择计算逐条依赖；`bid_package_input_dependencies.observe`只在单一RR／READ ONLY读取原packet，不读当前头／对象、不写Command／任务／Outbox。机器契约为package-input-dependencies/1；范围是内部可重算候选，公开接口、持久化、界面及正式任务范围外。

每条声明绑定准确要求ID／摘要、原规则权威冻结证据、明确unknown／not_needed／required、事实ID与理由。所需事实必须来自原prepared池，未选项报告missing而不自动消费；需要事实但无匹配值同样missing。未作声明、空清单或来源未证明为unknown；已选事实为selected_unvalidated；明确无事实依赖仅标human_dependency_annotation，不以名称、数量或覆盖verified／not_applicable推测无需事实。未声明要求不会丢弃，全部声明的declared只表示人工依赖标注覆盖，不认证规则抽取或客观完整性。原覆盖观察独立展示，inventory_complete和原件／事实／评审／执行／发布恒false。后续须独立核当前所选事实准入、输入完整性及任务条件。

规范摘要绑定准确冻结／prepared／清单、实际选择、逐条声明和政策源文件；要求排序及事实／证据集合排序，不受选择顺序影响。输出副本，不包含原事实值、未消费私有事实、证据正文或原件定位。候选不作历史落库，当前政策重算不能冒充原时点精确留存。
