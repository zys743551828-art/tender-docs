# 整包输入持久化与幂等冻结验证

2026-10-19；应用 `1e17cb6`、分支 `fusion/bid-workbench`。接续[候选上下文](../package-context/候选执行上下文与事实身份验证.md)，本批实现不可变输入表、冻结／历史读取接口和原命令回执。前端保存及恢复未接入，正式评审执行仍关闭。

## 实现与职责

新增 `POST .../{inventory_id}/frozen-review-inputs` 与 `GET .../{inventory_id}/frozen-review-inputs/{input_id}`。创建请求必须为明确选择五字段加候选 `context_digest`；actor来自会话，服务端生成ID和时点，不接受客户端正文、证据根或资格声明。

| 模块 | 职责 |
| --- | --- |
| `bid_package_review_input_routes` | 独立HTTP认证／严格契约、提交错误边界及原回执呈现 |
| `bid_package_review_freezing` | 原ACK优先、锁外原件核验、最终锁定事务重新捕获及原子保存 |
| `bid_package_review_input_repository` | 不可变记录／原命令回执读取与写入，不按当前头重建历史 |
| `read_in_snapshot` | 复用同一精确输入／事实／方法／来源捕获，由调用方提供事务 |
| 新DDL及最小权限补片 | 记录／根摘要绑定、不可变及提交时权威复核，API仅读／追加，Worker仅读 |

新 `package-review-frozen-input/1`、`kind=frozen_input` 保存明确主体／包／清单、actor／command及输入、上下文、证据根摘要。证据根 `package-review-evidence/1` 在不可变表保存完整选定输入、上下文和完整页／证据快照，剔除对象定位；以排序紧凑JSON原文的UTF-8字节SHA256绑定，不将几何浮点冒充无浮点规范摘要。外层manifest仍用规范摘要。正式条款、事实和决定权威沿用原表，没有第二套可写正文或事实状态。

同键同请求先读原ACK，重放不读对象、不按当前来源／生命周期重核旧记录；同键不同请求409。并发初次请求允许重复只读核验，最终bid锁及Command唯一约束只产生一份输入与ACK。原件IO不持业务连接或锁；最终事务重新捕获并比较，再将记录及ACK同事务提交。延期检查重用要求／身份／来源复核，另核完整事实／决定依据、成员、原件定位绑定、页／证据和摘要，来源在提交前过期不能得到成功ACK。fact_heads首次插入及更新复用原窄权限bid锁，不另建事实权威。

读取只验证原manifest、原根文本SHA和冻结身份，不依赖当前包、来源或对象存储；项目关闭／来源撤回后旧输入仍可读。普通Worker可读冻结输入但不能创建或改写；API不能UPDATE／DELETE。数据库无法代替应用读取外部原件字节，原件核验由服务端可信端口在锁外完成，测试对此明确使用内存对象流。

记录保留原阻断与待核事实资格，`review_ready`／`launch_available`恒false；保存不会启动模型、operation或评审。已冻结输入不等于已获得执行资格，后续执行仍需授权与发布前复核。
