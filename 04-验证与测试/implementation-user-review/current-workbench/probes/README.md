# 本轮探针留档

这里保留本轮实际使用的浏览器探针及公共请求保护；不是应用源码。包含本机私有会话路径引用，不包含访问资料内容、口令、Cookie或令牌文件。

输出路径和自有项目记录指向本轮环境。不要在原证据目录原地重跑；复现时先使用新的独立合成项目、私有会话与输出目录，保留本轮证据。运行需系统Chromium及Playwright，网络权限允许本地服务。脚本按可见DOM操作，前端改变时定位应重新核对，不能为脚本强迫产品修改。

请求保护禁止评审、准备评审、研究及模型写调用，构建仅允许follow_up=none；自有项目在上传前明确关闭自动评审。评审／模型入口不在本轮任务中。部分定位中断和实际服务变化见主报告，留档脚本不等于全部一次执行无中断。
