# 整包预检职责分层与冻结证据复核验证

2026-10-19；应用提交 `affdf2d`，分支 `fusion/bid-workbench`。接续[整包输入预检](../package-review-preview/整包评审输入预检验证.md)，仅推进F01-06的输入适配，不表示正式整包评审已完成。

## 职责与调用边界

| 模块 | 负责 | 边界 |
| --- | --- | --- |
| `bid_package_review_repository` | 精确读取所选包／清单／可选记录，校验选择关联；读取当前身份、头和来源观察 | 不创建记录，不判断正式执行资格 |
| `bid_package_review_documents` | 按已冻结解析ID读取文件定位、页和证据；核对文件摘要、页数、解析器／配置及完整证据摘要 | 不猜最新解析，不访问对象存储、不调用模型 |
| `bid_package_review_policy` | 用输入和观察计算阻断及物理页段缺口 | 纯计算，无数据库、存储、供应商或调度依赖 |
| `bid_package_review_preview` | 串联上述模块，返回选定manifest摘要与只读结果 | 不冻结新身份、不创建正式任务，不授启动资格 |

API继续提供认证与同一REPEATABLE READ／READ ONLY事务。公共解析身份读取新增显式 `lock=False` 的快照读取方式，既有包冻结／抽取调用仍默认加解析行锁；两条SQL均为固定文本、参数绑定，未更改授权或DDL。

未知解析保留成员未证明阻断。已冻结成员的实际记录无法匹配时新增 `PACKAGE_REVIEW_EVIDENCE_CHANGED`，界面显示中文说明；旧选定manifest和摘要不变。仅明确的证据领域错误转为阻断，数据库异常不被吞成正常结果。单块正文与单块摘要同时变更仍必须通过原先冻结的完整页／证据摘要。

数据库记录一致不代表对象存储原件字节通过；文件定位仅在服务内部使用，预检响应不增加原件定位或证据正文。`review_ready`、`launch_available`仍为false。

## 验证

- 固定 `tender-fusion` Compose checks运行[真实非owner数据库/API58项](evidence/requirements-api.xml)，64.75秒；包含前片49项与本片9项。本方／权威各覆盖正文损坏、正文及单块摘要同时变更、页面几何变化、解析器变化；新失败解析不能替换明确冻结的原解析，并实际以API LOGIN在只读事务读取完整页和证据。腐坏注入只在专用测试库由测试owner执行，不是业务修复路径，也没有赋予运行角色绕过权限。
- [领域／契约37项](evidence/pure.xml)，1.79秒；补齐两个旧接口枚举的遗漏（证据目录与预检），仍严格检查仅注册路由。第一次未加UTF-8开关产生4个Windows编码失败，显式UTF-8后暴露2个旧枚举失败；保留[编码失败XML](evidence/pure-without-utf8.xml)及[旧枚举失败XML](evidence/pure-before-route-expectations.xml)，不计通过。未改产品编码逻辑规避测试。
- [受影响前端预检组件9项](evidence/frontend.xml)通过，2.21秒；新增实际证据不匹配的中文阻断呈现。此次未重跑完整前端，前片284项不计为本批结果。
- [ruff](evidence/ruff.log)、[format](evidence/format.log)9文件通过；[mypy](evidence/mypy.log)、[bandit](evidence/bandit.log)6源通过。前端受影响文件格式／eslint、tsc通过，生产构建2.32秒、入口496.74kB，既有助手混合导入提示保留。无新CSS或浮层规则。
- [专用库和两个测试账号剩余均0](evidence/cleanup.json)，checks及检查PG停止；[固定Compose状态](evidence/services.txt)默认三服务healthy、init退出0。现有fusion_v3无DDL变化，原合成项目保留，新增阻断在运行API契约已注册，见[部署核对](evidence/deployment.json)。

## 后续

正式执行仍需明确冻结方法、用途、事实、来源效力时点，并在业务锁外核验对象存储实际原件字节、回事务复核后发布；执行端必须消费完整冻结身份，不把预检候选或当前单正文指针当作整包输入。评分、比较、提交仍待对应适配。

项目仍无真实文件／包／清单。本批未新增实际浏览器预检交互或桌面／手机截图，不能把组件测试当作视觉验收，也不以合成证据证明真实OCR／抽取质量。
